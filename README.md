# Fome e Frio 

## Executar

Na raiz do projeto:

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

## Controles

- **Mouse**: única entrada necessária para navegar. Clique em locais, personagens, pistas, premissas e botões.
- **1, 2, 3**: escolhem a opção correspondente durante uma conversa.
- **Roda do mouse**: rola o histórico de deduções.
- **ESC**: fecha primeiro o diálogo, o diário, o histórico ou a ficha aberta; depois retorna da mesa de dedução ao local, do local ao mapa, e do menu encerra o jogo.
- **Botões de fechar**: cada painel também oferece seu próprio botão de saída, para quem joga apenas com o mouse.
